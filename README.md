# ごっくんアニメ 〜おにぎりくんの のど たんけん〜

▶ **アニメをみる:** https://sakusaku117.github.io/gokkun-anime/

飲み込み(嚥下)のときに、のどの中で何が起きているのかを、おにぎりのキャラクターと一緒に見られるアニメーションです。小学生から大人まで、スマートフォンで見られます。

`index.html` をブラウザで開くだけで使えます。インストールや通信は不要です。

## おはなし

| おはなし | 内容 |
|---|---|
| 🍙 じょうずに ごっくん | 正しい飲み込み。鼻への道がしまる → のどぼとけが上がる → 気管にふた → のどがギュッとしまって食道へ |
| 💦 あれれ? むせちゃった | 誤嚥。おしゃべりしながら食べて、飲み込む前に食べ物が気管に入り、むせて押し出す |

それぞれ20秒ほどです。説明は、アニメの中に短い吹き出しで出ます。のどの動き(咽頭期)は、ほんとうは1秒もかからないので、スローモーションで見せています。

## 使い方

- メニューで、見たいおはなしを選びます。
- 「とめる」「はじめから」のボタンと、下のバーで、好きな場面に戻れます。
- 「ゆっくりに」を押すと、再生の速さが少し遅くなります。
- 効果音は、「おと」のボタンで切り替えます。最初は音なしです。
- メニューのボタンで、ふりがなの表示を切り替えられます。

## プライバシー

名前などの入力欄はありません。どこにも送信・保存されません。アクセス解析や外部サービスの読み込みもありません。

## ご注意

このアニメーションは、一般の方向けに飲み込みのしくみを紹介するもので、からだの形や動きはわかりやすく簡単にしています。病気の診断をするものではありません。飲み込みについて気になることがあるときは、医師や言語聴覚士にご相談ください。
